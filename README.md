# CODSOFT Data Science 

🌸 Data Science Internship Projects

## 📊 Overview

This repository contains five Data Science and Machine Learning projects completed during my internship. These projects demonstrate the application of data analysis, visualization, classification, regression, and anomaly detection techniques using Python.

## 📊 Projects Included

🚢 1. Titanic Survival Prediction

Built a machine learning model to predict passenger survival on the Titanic using demographic and travel-related features. Performed data preprocessing, exploratory data analysis, feature engineering, and classification modeling.

🎬 2. Movie Rating Prediction

Developed a regression model to predict movie ratings based on various movie attributes. Analyzed relationships between features and ratings to improve prediction performance.

🌸 3. Iris Flower Classification

Created a classification model to identify Iris flower species (Setosa, Versicolor, and Virginica) using sepal and petal measurements. Achieved high prediction accuracy through machine learning techniques.

📈 4. Sales Prediction Using Python

Designed a predictive model to estimate product sales based on advertising expenditures. Used data visualization and regression analysis to understand the impact of marketing channels on sales.

💳 5. Credit Card Fraud Detection

Implemented a fraud detection system capable of identifying suspicious credit card transactions. Addressed class imbalance and evaluated model performance using appropriate metrics.
